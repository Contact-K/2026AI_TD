レベル3画像をテンソルにして MLP へ入れる✔ クリア

モデルが計算できるのはテンソル（数の並び）だけ．画像をテンソルにし，MLP の最初の層が受け取れる形にそろえるまでを追う．

← 幅 28 画素 →
↑高さ28画素↓

FashionMNIST の画像（例：T シャツ）は，縦 28 × 横 28 ＝ 784 個の画素（小さな四角）でできた白黒画像．

画素は 1 つずつ明るさを表す数を持つ．0 が黒，255 が白，その間が灰色．

白黒なので色の層（チャネル）は 1 枚．カラーなら R・G・B の 3 枚になる（レベル3+）．

つまり 1 枚の画像は「チャネル 1 × 高さ 28 × 幅 28」の数の集まり．以下，この画像がどんな形のテンソルになってモデルに入るかを追う．

0.00.51.0

① 画素の明るさ 0〜255 を 0〜1 の数にし，[チャネル, 高さ, 幅] のテンソルにする（白黒なのでチャネル 1）．

なぜ 0〜1 にするのか：1 層目の Linear は「784 個の画素 × 重み」を全部足す．重みの初期値は 0〜1 くらいの入力を想定した小さな値なので，画素が 0〜255 のままだと出力も約 255 倍に膨らむ．数が大きすぎると，1 回の更新で重みが動きすぎて学習が壊れる．

FashionMNIST 5,000 枚で実際に学習させた値．授業で使う Adam は壊れにくいが，それでも正解率の上下が大きくなった．

レベル3+次元を入れ替える✔ クリア

カラー画像（チャネル 3＝R・G・B，高さ 240，幅 320）で練習する．同じ画像でも，チャネルが先か後かで並びが違う．

RGB

PyTorch：[3, 240, 320]
色ごとの面を 3 枚重ねる

NumPy・matplotlib：[240, 320, 3]
1 画素ごとに R・G・B の 3 つ

x.permute(a, b, c) は「新しい並びの 0 番目に元の a 番目，1 番目に元の b 番目，…」を置く．空欄に元の次元の番号を入れる．

# ① PyTorch の画像を matplotlib で表示したい img.shape # [3, 240, 320] # 0 1 2 ← 次元の番号 img.permute(, , ) # → [240, 320, 3]
# ② NumPy で読んだ画像を PyTorch に渡したい arr.shape # [240, 320, 3] # 0 1 2 ← 次元の番号 torch.from_numpy(arr).permute(, , ) # → [3, 240, 320]
# ③ ミニバッチ 64 枚をまとめて表示用の並びにしたい imgs.shape # [64, 3, 240, 320] # 0 1 2 3 ← 次元の番号 imgs.permute(, , , ) # → [64, 240, 320, 3]

高さと幅を取り違えると [320, 240, 3] になり，画像が縦横入れ替わって崩れる．
